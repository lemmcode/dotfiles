# Личные конфигурации Linux

Конфигурации для GNU Stow: `zsh`, `ghostty`, `herdr`, `micro` и `lf` — отдельные пакеты.
За основу взяты текущие настройки; из конфигурации Herdr убраны плагины и их оформление.
Рекомендуемое расположение репозитория — `~/dotfiles`. GNU Stow связывает файлы
из пакетов с домашним каталогом, оставляя состояние приложений локальным.

## Состав

- `zsh` — исправленная конфигурация и пользовательский `~/.zshenv`.
  Подробности — в `docs/zsh.md`.
- `ghostty` — конфиг Ayu, размер шрифта 10 и используемый шейдер `starfield.glsl`.
- `herdr` — только `config.toml`, без зависимостей от плагинов.
  Сохраняются prefix `Ctrl+A`, тема Catppuccin, уведомления и подписи агентов.
- `micro` — настройки и используемая тема Catppuccin Macchiato.
  Подсветка языков — встроенная, bindings — стандартные.
- `lf` — `lfrc` с включёнными иконками и файл `icons`.

История shell, локальные настройки zsh, SSH-конфиги, keyring, сессии Herdr,
snapshots, логи, реестр плагинов и их исходники не включены. История буферов и
backups micro, история и отметки lf также остаются локальными.

## Зависимости

Для получения и развёртывания конфигураций установи **Git** (`git`) и
**GNU Stow** (`stow`). Затем установи приложения для выбранных пакетов:

| Пакет Stow | Приложение |
|---|---|
| `zsh` | Zsh (`zsh`) |
| `ghostty` | Ghostty (`ghostty`) и Zsh — он указан как запускаемый shell |
| `herdr` | Herdr (`herdr`), без дополнительных плагинов |
| `micro` | Micro (`micro`) |
| `lf` | lf (`lf`) |

Для полной функциональности zsh также установи:

| Утилита | Для чего используется |
|---|---|
| `eza` | Aliases `ls`, `ll`, `la`, `tree` с иконками |
| `fzf` | Поиск файлов, истории, каталогов и SSH-хостов |
| `fd` или `fdfind` | Быстрый поиск файлов для fzf |
| `bat` или `batcat` | Предпросмотр файлов в fzf и просмотр man-страниц |
| `zoxide` | Навигация по часто используемым каталогам |
| `starship` | Приглашение с каталогом, Git-статусом и версиями языков |
| OpenSSH client (`ssh`) | SSH picker и подключения к выбранным хостам |

Эти дополнительные утилиты необязательны для запуска shell. Без `eza` остаётся
стандартный `ls`, без `fd` используется `find`, без `bat` — `head`, а без Starship —
стандартное приглашение. Для иконок в терминале выбери **Nerd Font** или совместимый
шрифт. Отдельно скачивать темы Catppuccin, шейдер Ghostty или подсветку micro не нужно.

Стандартные команды Linux (`awk`, `grep`, `sort`, `find`, `head`, `mkdir`, `mktemp`,
`rm`, `tty`) должны быть доступны через `PATH`. Названия системных пакетов зависят
от дистрибутива; в таблицах указаны команды. Stow не устанавливает приложения.
Плагины zsh скачиваются автоматически при первом запуске — нужен доступ к GitHub.

## Развёртывание

Команды развёртывания рассчитаны на стандартные
XDG-каталоги внутри `$HOME/.config`. Сначала из корня этого репозитория проверь план:

```sh
stow --simulate --verbose --no-folding --target="$HOME" zsh ghostty herdr micro lf
```

При конфликтах сохрани существующие файлы отдельно и освободи только те пути,
которые перечислены в плане. Stow не должен перезаписывать настройки автоматически.
Не используй `--adopt` без отдельной проверки: он переносит существующие файлы
в checkout и может заменить подготовленную конфигурацию.

После устранения конфликтов:

```sh
stow --verbose --no-folding --target="$HOME" zsh ghostty herdr micro lf
```

`--no-folding` оставляет каталоги обычными и связывает отдельные файлы:
локальное состояние приложений не должно попадать внутрь checkout.
Можно разворачивать пакеты по одному, например только `zsh`.

После развёртывания изменяй файлы в репозитории: приложения читают их через symlink.
Не перемещай и не удаляй репозиторий, пока ссылки подключены.
Повторный запуск той же команды Stow безопасен и не должен планировать новых ссылок.
Чтобы отключить пакеты, сохранив исходники в репозитории:

```sh
stow --delete --no-folding --target="$HOME" zsh ghostty herdr micro lf
```

Для переноса репозитория сначала отключи пакеты, перенеси каталог, затем подключи
их из нового расположения. Перед изменениями на другой машине всегда проверяй dry-run.

## Ghostty

В конфиге используется `zsh`, найденный через `PATH`: он должен быть установлен
на второй машине. Шейдер задан относительно `~/.config/ghostty`, поэтому не зависит от имени
пользователя. Значение `custom-shader-animation = always` сохранено: анимация
работает и в неактивных окнах. Для ноутбука можно выбрать `true` — анимацию только
в активном окне, либо `false` — перерисовку только при обновлении терминала.

Проверка конфигурации без открытия окна:

```sh
ghostty +validate-config --config-file=ghostty/.config/ghostty/config.ghostty
```

## Herdr

Конфигурация использует стандартное оформление sidebar без quota-полей и
плагиновых shortcuts. Устанавливать плагины для неё не требуется.

Настройки и реестр плагинов, авторизация агентов, кеши, логи и сессии не включены.
Развёртывание конфигурации не удаляет плагины, уже установленные на машине.

## Micro и lf

Установи `micro` и `lf` отдельно. Для иконок lf нужен Nerd Font или совместимый шрифт
в терминале. lf читает файл `~/.config/lf/icons` напрямую; экспортировать `LF_ICONS`
из shell не требуется.

В micro переносятся только настройки и активная тема. Пользовательского `syntax/`
нет: micro содержит встроенные правила подсветки. История `buffers/`, backups и
кеши не включены. Плагины не добавлены.

## Происхождение файлов

Конфигурация zsh основана на [radleylewis/zsh](https://github.com/radleylewis/zsh).
Исходная MIT-лицензия сохранена в `docs/licenses/zsh-MIT.txt`.
Она не назначается автоматически другим файлам репозитория.
Тема micro — вариант Catppuccin Macchiato из
[catppuccin/micro](https://github.com/catppuccin/micro).
MIT-лицензия проекта сохранена в `docs/licenses/catppuccin-MIT.txt`.

`starfield.glsl` — локальная модификация шейдера из
[hackrdotsh/ghostty-shaders](https://github.com/hackrdotsh/ghostty-shaders/blob/main/starfield.glsl).
Изменены прозрачность, порог фона, количество слоёв, плотность, размер, яркость
и скорость звёзд. В исходном репозитории отдельная лицензия не указана;
лицензия zsh или Catppuccin на этот файл не распространяется.
