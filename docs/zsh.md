# Конфигурация zsh для Linux

Личная конфигурация на основе [radleylewis/zsh](https://github.com/radleylewis/zsh).
Исходный автор — Radley Sidwell-Lewis; исходная лицензия MIT сохранена в `licenses/zsh-MIT.txt`.

## Зависимости

Общий список приложений и назначение утилит — в [README](../README.md#зависимости).

Для полной функциональности: `zsh`, `git`, `micro`, `eza`, `bat`, `fd`, `fzf`,
`zoxide`, `starship`, `lf`, `openssh`. Для значков Starship нужен Nerd Font в терминале.
На Debian/Ubuntu поддерживаются также имена `batcat` и `fdfind` без создания symlink.

Дополнительные утилиты подключаются при наличии. Без Starship остаётся стандартное
приглашение zsh, без zoxide — обычная навигация, без eza — стандартный `ls`.
Без fd поиск fzf использует `find`, без bat — предпросмотр через `head`.
`cat` и `grep` сохраняют стандартное поведение. Системные пакеты автоматически не устанавливаются.

## Загрузка

Файлы конфигурации находятся в `${XDG_CONFIG_HOME:-$HOME/.config}/zsh`.
Пользовательский `~/.zshenv` служит точкой входа и должен содержать:

```zsh
export XDG_CONFIG_HOME="${XDG_CONFIG_HOME:-$HOME/.config}"
export ZDOTDIR="$XDG_CONFIG_HOME/zsh"
if [[ -r "$ZDOTDIR/.zshenv" ]]; then
  source "$ZDOTDIR/.zshenv"
fi
```

Правки `/etc/zsh/zshenv` для установки не требуются. Если там уже задан `ZDOTDIR`,
системная настройка определяет, где zsh ищет `.zshenv`. На этом ПК она указывает
на тот же каталог конфигурации.

`.zshenv` задаёт XDG-каталоги, `PATH` без повторов и редактор micro, если он установлен.
Уже заданные XDG-пути сохраняются. `.zshrc` подключает настройки интерактивного shell.
Каталоги истории и completion создаются при запуске; история хранится в
`$XDG_STATE_HOME/zsh/history`, completion — в `$XDG_CACHE_HOME/zsh/zcompdump`.
Эти данные не нужно синхронизировать через Git.

Для настроек отдельной машины создай `$ZDOTDIR/local.zsh`: он подключается последним
и исключён из Git. История, SSH-конфиги, ключи и keyring остаются локальными.
После обновления конфигурации открой новый терминал.

## Модули

- `aliases.zsh` — aliases и переход в каталог, выбранный в lf.
- `fzf.zsh` — поиск файлов и предпросмотр.
- `plugins.zsh` — установка, загрузка и явное обновление плагинов.
- `bindings.zsh` — назначения клавиш после загрузки плагинов.
- `prompt.zsh`, `starship.toml` — приглашение Starship.
- `ssh-picker.zsh` — выбор SSH-хостов и completion.

## Плагины

Используются `zsh-autosuggestions`, `zsh-history-substring-search` и
`fast-syntax-highlighting`; vi mode не подключается.

Плагины находятся в `$XDG_DATA_HOME/zsh/plugins`, отдельно от конфигурации.
При первом запуске отсутствующие плагины скачиваются через `git clone --depth=1`.
Для этого нужны Git и доступ к GitHub. Ошибка установки не прерывает загрузку shell;
следующий запуск повторит установку, если каталог плагина отсутствует.
Существующие плагины загружаются без обновления. Для явного обновления:

```zsh
zplugin-update
```

Версии не закреплены. Чтобы обе машины получили актуальные версии, выполни команду
на каждой. Если обновление одного плагина завершится ошибкой, остальные тоже будут
проверены, а команда вернёт ненулевой код. При прерванной установке с оставшимся
неполным каталогом убери этот каталог перед повторной установкой.

## Клавиши и команды

| Сочетание | Действие |
|---|---|
| `Ctrl+R` | Поиск по истории через fzf |
| `Ctrl+T` | Выбор файла, включая скрытые, через fzf |
| `Ctrl+F` | Выбор одного файла без скрытых; путь вставляется с shell-экранированием |
| `Alt+C` | Выбор каталога через fzf |
| `Ctrl+→`, `Ctrl+←` | Перемещение по словам |
| `↑`, `↓` | Поиск по подстроке в истории |
| `Ctrl+\` | Включение и выключение autosuggestions |
| `Ctrl+P` | Выбор SSH-хоста и подключение |

Сочетания дополнительных инструментов подключаются только при их наличии.
Для стандартных виджетов fzf выбирается одна интеграция: `/usr/share/fzf`,
`/usr/share/doc/fzf/examples` или `~/.fzf/shell`, в таком порядке.

`sshp` открывает тот же SSH picker, что и `Ctrl+P`. Picker и completion используют
единый источник: простые директивы `Host` из `~/.ssh/config` и `~/.ssh/conf.d/*.conf`.
Шаблоны и отрицательные записи не предлагаются. Вложенные `Include` за пределами
этих файлов не обходятся; все файлы `conf.d/*.conf` читаются независимо от `Include`.
Чтобы подключение работало, соответствующие файлы должны быть подключены и в SSH-конфиге.

`lf` после успешного выхода переводит shell в выбранный каталог. `ls`, `ll`, `la`
и `tree` используют eza при его наличии; без eza `ll` и `la` используют стандартный ls.
`m` запускает micro, если он установлен. `df` показывает размеры в читаемом виде.
